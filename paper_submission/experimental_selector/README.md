# Experimental MSR-VTT Generated-Beam Selector

This directory contains post-submission experimental analysis code for a frozen
selector trained on generated MSR-VTT beam candidates. It is not part of the
audited reproducibility-package manifest and should not be cited as the primary
manuscript result unless the manuscript is updated accordingly.

## Purpose

The selector is trained on alternatives generated by the tuned MSR-VTT captioner,
not on human-caption stand-ins. The intended workflow is:

1. Generate MSR-VTT beam candidates from a trained captioner checkpoint with
   `scripts/beam_headroom_diagnostic.py`.
2. Train the frozen Dattalion candidate selector with
   `scripts/train_frozen_learned_selector.py --msrvtt-beam-run-dir <beam_cache>`.
3. Bootstrap held-out Dattalion differences with
   `scripts/bootstrap_dattalion_cis.py`.

The local run used a sampled cache of 750 MSR-VTT videos, 500 train and 250 val,
with beam-8/return-8 candidates from
`outputs/final_bart_full_tuned_continue_v3/best_cider_xe.pt`.

## Current Local Result

Under the v3 MSR-VTT-style Dattalion references:

| Method | Test CIDEr | Gain vs clean baseline |
| --- | ---: | ---: |
| Clean BART baseline | 0.2221 | 0.0000 |
| Plain frozen Ridge selector | 0.2323 | 0.0102 |
| LV-ECR rerun | 0.2395 | 0.0173 |
| MSR-VTT generated-beam Ridge selector, dev-selected | 0.2464 | 0.0243 |
| MSR-VTT generated-beam Ridge selector, exploratory | 0.2593 | 0.0372 |

The dev-selected generated-beam row used pretraining weight `0.001`, selected by
development out-of-fold CIDEr. The stronger `0.0005` row should be treated as
exploratory because it was not the dev-selected weight.

See `results/msrvtt_style_reference_rerun_summary.md` and
`results/bootstrap_msrvtt_style_refs_v3_msrvtt_beam_selector.md` for the compact
summary and bootstrap intervals.

## Artifact Policy

Generated beam caches and prediction dumps are intentionally not committed here.
They are local derived artifacts and can be regenerated from the scripts above
when the trained checkpoint and processed MSR-VTT/Dattalion workspaces are
available.
