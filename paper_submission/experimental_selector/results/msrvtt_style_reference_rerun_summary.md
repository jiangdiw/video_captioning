# MSR-VTT-Style Reference Normalization Rerun

This diagnostic should not replace the original Dattalion held-out references for the
primary manuscript result. It evaluates whether Dattalion's lower lexical consistency
is suppressing automatic caption metrics relative to the MSR-VTT reference style.

## Learned Selector Diagnostic

The frozen learned selector trains only on the development videos and chooses from
the same LV-ECR candidate pool. Hyperparameters are selected with video-grouped
cross-validation before the final test scoring pass.

| Selector | Test CIDEr | CIDEr gain vs clean baseline | Test source counts |
| --- | ---: | ---: | --- |
| Clean model-score baseline | 0.2221 | 0.0000 | `{'bart': 30}` |
| Frozen Ridge selector | 0.2323 | 0.0102 | `{'bart': 30}` |
| Frozen pairwise selector | 0.2299 | 0.0078 | `{'bart': 29, 'evidence_summary': 1}` |
| MSR-VTT reference-proxy Ridge selector | 0.2585 | 0.0364 | `{'adaptive_blip': 2, 'bart': 28}` |
| MSR-VTT generated-beam Ridge selector, dev-selected | 0.2464 | 0.0243 | `{'bart': 30}` |
| MSR-VTT generated-beam Ridge selector, exploratory | 0.2593 | 0.0372 | `{'bart': 30}` |
| LV-ECR rerun | 0.2395 | 0.0173 | `{'bart': 30}` |
| Candidate-pool oracle | 0.5132 | 0.2910 | `{'adaptive_blip': 5, 'bart': 16, 'evidence_summary': 9}` |

The plain learned selectors are directionally above the clean baseline but do not
improve over the LV-ECR rerun on CIDEr. The reference-proxy MSR-VTT pretraining
result is promising but should not be treated as the clean selector result because
it trains on human-caption stand-ins rather than model-generated alternatives.

The generated-beam selector is the cleaner version of the idea: it pretrains on
6,000 beam candidates generated by the tuned MSR-VTT captioner over 750 sampled
MSR-VTT train/val videos. The pretraining weight chosen by dev out-of-fold CIDEr is
0.001, giving 0.2464 test CIDEr. The adjacent 0.0005 weight reaches 0.2593 test
CIDEr, but that row should be treated as exploratory unless the weight is frozen
before another held-out evaluation.

## Interpretation

The MSR-VTT-style normalization raises absolute Dattalion CIDEr scores substantially,
which supports the concern that the original references are unusually lexically
heterogeneous. The main model-ranking story remains cautious: LV-ECR is still above
the clean model-score baseline in the full rerun, but the paired CIDEr interval still
includes zero. The normalized-reference result is therefore best framed as a
sensitivity analysis, not a replacement for the primary benchmark result.

The bootstrap script reported fallback tokenization/METEOR/ROUGE paths, so CIDEr and
relative trends are the safest numbers to cite from this diagnostic.
